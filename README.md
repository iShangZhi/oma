
# OMA Platform
开源 AI 智能体运行与管理平台，提供沙箱执行、任务编排和人工审核，让智能体协作可管理、可追踪、可验收

**Open Managed Agents**

一个开源的 AI 智能体运行与管理平台。

OMA 将模型、工具、技能和执行环境组织到统一的项目空间，
帮助团队分配任务、运行智能体、追踪执行过程并审核交付结果。

人确定目标，智能体执行任务，团队掌握过程与结果。

## 为什么选择 OMA

从一次模型调用到可靠地完成一项任务，还需要处理执行环境、
任务调度、上下文管理、故障恢复与结果审核。

OMA 为这些工作提供统一的管理入口，让团队能够持续运行和管理
AI 智能体，将它们融入实际的研发与业务流程。

## 核心能力

### 项目空间

围绕项目组织成员、任务和智能体资源，
为团队协作提供统一上下文。

### 智能体与技能

管理不同职责的智能体，组合可复用的技能与工具，
根据任务需要配置执行能力。

### 任务编排

管理任务队列与执行状态，通过工作流组织多个执行步骤，
支持人与智能体共同推进任务。

### 沙箱执行

在项目级沙箱中执行任务，隔离运行环境，
管理沙箱生命周期并保留项目工作区。

### 模型接入

统一管理模型服务和访问配置，
为不同任务选择合适的模型。

### 执行追踪

查看任务状态、执行日志与产出，
帮助团队理解过程、定位问题和审核结果。

## 工作方式

1. 创建项目，配置执行环境。
2. 选择智能体、技能与模型。
3. 提交任务，明确目标和交付要求。
4. 平台调度智能体，在沙箱中执行。
5. 跟踪执行过程，按需补充说明或人工介入。
6. 审核结果，继续迭代或完成验收。

## 架构概览

OMA 将平台管理与任务执行分开：

- Web 控制台：项目、任务、资源配置与运行状态。
- 平台服务：身份认证、任务编排、资源管理与执行协调。
- 执行沙箱：运行智能体及项目代码，保存工作区与产出。
